# 禅修功课管理系统 - UI/UX 设计规范

## 一、设计理念

### 核心原则
- **宁静禅意**：采用温和的色调，营造平和的修行氛围
- **简约高效**：去除冗余元素，专注核心功能
- **微拟物化**：适度使用阴影、渐变，增加质感但不过度
- **流畅自然**：动画柔和，交互符合直觉

---

```

### 2. 字体规范

#### 字体家族
```

#### 字号体系
```
- H1 大标题: 32px / bold
- H2 页标题: 28px / bold
- H3 区块标题: 24px / medium
- H4 卡片标题: 20px / medium

- Caption 辅助: 14px / regular
- Small 小字: 12px / regular
```

### 2. 呼吸球动画 (Breathing Ball)

#### 视觉设计
- 圆形球体，中心到边缘渐变
- 吸气：球体放大 1.2x，3-5秒
- 呼气：球体缩小至 0.8x，3-5秒
- 颜色随状态变化：
  - 慢节奏: #9B59B6 → #E8D5F2 (紫色系)
  - 中节奏: #4A90E2 → #D1E8FF (蓝色系)
  - 快节奏: #67B26F → #D5F2DB (绿色系)

#### 交互
```
   吸气 (Inhale)
        ↓
    ◉ → ⭕
        ↓
   呼气 (Exhale)
        ↓
    ⭕ → ◉
```

## 五、交互设计

### 1. 三步核心流程

```
第一步：选择功课
  ↓ (点击功课卡片)
第二步：设置参数
  ↓ (设置时长/禅音/节奏)
第三步：开始执行
  ↓ (进入计时页面)
完成！
```

### 2. 动画规范

#### 页面切换
- 类型: 平滑滑动 (slide)
- 时长: 300ms
- 缓动: cubic-bezier(0.4, 0, 0.2, 1)

#### 按钮反馈
- 按下: scale(0.95)
- 时长: 100ms
- 缓动: ease-out

#### 卡片展开
- 高度: 自动
- 时长: 250ms
- 缓动: ease-in-out

#### 呼吸球
- 吸气/呼气: 3-5秒
- 缓动: ease-in-out
- 循环: 无限

### 3. 手势操作

- **滑动删除**: 卡片左滑显示删除按钮
- **下拉刷新**: 列表页下拉刷新数据
- **长按**: 长按功课卡片进入编辑模式

## 六、响应式设计

### 断点
```
- 手机: < 768px
- 平板: 768px - 1024px
- 桌面: > 1024px
```

### 适配策略
- 使用 rpx 单位（uniapp 自动转换）
- 图片使用 2x/3x 倍图
- 字体最小 12px，不随屏幕缩放过小

---

## 七、无障碍设计

- 色彩对比度 ≥ 4.5:1
- 可点击区域 ≥ 44x44px
- 语义化标签
- 支持屏幕阅读器

## 八、优化建议

### 功能优化
1. **智能推荐**: 基于用户习惯推荐功课时间
2. **数据备份**: 支持导出/导入JSON数据
3. **社交功能**: 打卡分享到社交平台
4. **成就系统**: 连续打卡徽章、里程碑
5. **离线模式**: PWA支持，离线也能使用
6. **音频优化**: 支持自定义禅音上传
7. **日历视图**: 月历展示完成情况
8. **统计增强**: 更丰富的图表（折线图、热力图）

### 体验优化
1. **首次引导**: 新用户引导流程
2. **空状态**: 优雅的空列表提示
3. **加载动画**: 禅意的加载动画
4. **错误处理**: 友好的错误提示
5. **快捷操作**: 快速开始最近功课
6. **语音提示**: 执行时语音引导
7. **深色模式**: 夜间护眼模式
8. **多语言**: 支持中英文切换
