前置要求

  • Java 17 或更高版本
  • Maven 3.6+
  • Node.js 16+
  • 网络连接（用于下载依赖）

方式一：使用启动脚本（推荐）

# 启动后端
./start-backend.sh

# 启动前端（新开终端）
./start-frontend.sh

方式二：手动启动

步骤1：启动后端

cd backend
mvn spring-boot:run

步骤2：启动前端（新开终端）

cd frontend
npm install
npm run dev:h5
⚠️ 当前环境限制
在当前受限环境中无法下载Maven依赖，请在本地开发环境中启动应用。

🎯 使用流程演示

流程1: 从零开始

  1. 访问首页（功课列表）
  2. 点击"💡 推荐"按钮 → 一键添加8个推荐功课
  3. 点击"晨起梦观"卡片的"开始"按钮
  4. 进入执行页 → 看到呼吸球动画
  5. 点击"设置" → 调整时长/禅音/节奏
  6. 点击"开始" → 计时开始
  7. 点击"完成" → 完成本次修行

流程2: 创建每日计划

  1. 切换到"计划"Tab
  2. 选择日期，点击"编辑计划"
  3. 勾选多个功课，设置时长
  4. 设置起始时间（例如07:00）
  5. 保存计划（自动计算时间段）
  6. 点击"批量生成" → 输入天数（1-60）
  7. 查看未来计划已生成

流程3: 查看统计

  1. 切换到"统计"Tab
  2. 选择范围（今日/本周/本月/全部）
  3. 查看总时长、功课分布、最近会话
